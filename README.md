# 🧠 Локалка

**Помощник по программированию, который помещается на флешке**

Пишешь задачу обычными словами — он пишет код, запускает его, проверяет и объясняет решение.
И запоминает тебя: с каждым занятием он знает о тебе и твоём курсе всё больше.

</div>

---

## ✨ Что он умеет

|  |  |
|---|---|
| 💬 **Понимает задачу словами** | Вставь условие целиком, как в задачнике — он разберётся |
| ✍️ **Пишет и правит код сам** | Создаёт файлы, исправляет ошибки, доводит до рабочего состояния |
| ▶️ **Проверяет решение** | Запускает программу на примере из условия и на хитрых случаях |
| 🎓 **Объясняет просто** | В конце — суть решения в паре фраз, чтобы ты мог пересказать |
| 🧠 **Второй мозг** | Помнит прошлые занятия, требования преподавателя и твои частые ошибки |
| 🔌 **Работает с любым ключом** | OpenRouter, OpenAI, Claude, Gemini, DeepSeek, Groq, Mistral, Grok и другие |
| 💾 **Ничего не устанавливает** | Работает прямо с флешки, на компьютере не оставляет следов |
| 🛡️ **Спрашивает разрешения** | Перед каждым изменением показывает, что именно собирается сделать |

## 🚀 Как начать

**1. Скачай** — зелёная кнопка **Code → Download ZIP** вверху этой страницы. Распакуй папку на флешку.

**2. Запусти** — двойной щелчок по **`run.bat`**.
Или открой терминал (например, в PyCharm) в папке с задачей и введи путь к `run.bat` на флешке.

**3. Настрой один раз** — выбери, чей у тебя ключ, вставь его и выбери модель из списка.
Всё запомнится — в следующий раз сразу к делу.

> 💡 **Нет ключа?** Возьми на [openrouter.ai](https://openrouter.ai) — один ключ открывает модели всех компаний и работает почти везде.

## 💬 Как это выглядит

```
> вводится N, вывести сумму его цифр. сохрани в sum.py и проверь

  > write_file sum.py
    Разрешить? [Enter — да / n — нет / a — больше не спрашивать]
  > run_command python sum.py

Готово: решение в sum.py, проверил на 1234 → 10 и на 0 → 0.
Идея: берём последнюю цифру как остаток от деления на 10
и отбрасываем её, пока число не станет нулём.
```

Не нравится, что он предлагает? Вместо «нет» просто напиши, как сделать иначе, — он учтёт.

## 🧠 Второй мозг

Локалка ведёт собственный граф знаний — сеть заметок, связанных между собой.
Она сама записывает туда то, что пригодится позже:

- 📚 твой курс и язык, на котором вы пишете
- 👩‍🏫 требования преподавателя: «комментарии на русском», «без встроенной сортировки»
- 🧩 решённые задачи и их главную идею
- 🐞 ошибки, которые повторяются, и как их исправить

Заметки связаны: задача про факториал ведёт к теме «Рекурсия», а та — ко всем остальным задачам на рекурсию.
Начинаешь новое занятие — помощник уже в курсе.

```
> /brain

Заметок: 5, связей: 4
  ● Курс               →  Python, Преподаватель
  ● Задача: факториал  →  Рекурсия
  ● Рекурсия           →  Задача: факториал
  ...
```

Память хранится на флешке, рядом с программой, и никуда больше не уходит.

---

## ⌨️ Команды

| Команда | Что делает |
|---|---|
| `/brain` | показать второй мозг — все заметки и связи |
| `/brain слово` | найти в памяти |
| `/forget тема` | стереть заметку |
| `/model` | сменить модель |
| `/setup` | сменить провайдера или ключ |
| `/auto` | больше не спрашивать разрешения |
| `/undo` | отменить последнее изменение файла |
| `/clear` | начать разговор заново |
| `/cd папка` | перейти в другую папку |
| `!команда` | выполнить свою команду в терминале |
| `/help` | все команды |
| `/exit` | выйти |

`Ctrl+C` — остановить ответ, если он пошёл не туда.

---

## 🔐 Про ключ на чужом компьютере

- Ключ и память хранятся **только на флешке**. Запускай прямо с неё, не копируй папку на учебный компьютер.
- Поставь в кабинете провайдера **лимит трат** на ключ — так спокойнее.
- Потерял флешку — просто отзови ключ и создай новый.

---

## 🛟 Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| **HTTP 401** | ключ неверный — `/key` и вставь заново |
| **HTTP 403** или **нет связи** | сервис недоступен из этой сети — попробуй OpenRouter |
| **HTTP 404** | такой модели нет — `/model` |
| **Слишком длинный диалог** | `/clear` |
| **Python не найден** | на компьютере нет Python — смотри ниже |

<details>
<summary><b>Что делать, если на компьютере нет Python</b></summary>

<br>

1. Зайди на [python.org/downloads/windows](https://www.python.org/downloads/windows/) и скачай **Windows embeddable package (64-bit)** — это архив примерно на 10 МБ.
2. Распакуй его в папку **`python`** рядом с `run.bat` — чтобы получилось `локалка\python\python.exe`.

Готово: `run.bat` найдёт его сам. Делается один раз дома — дальше флешка работает на любом компьютере.

</details>
